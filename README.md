# 👋 Projeto Olá Mundo

Este projeto é uma aplicação simples de console em **C# utilizando .NET**.

O programa apenas exibe um texto no terminal.

---

## 🛠️ Comandos Utilizados

- `dotnet new console`  
  Cria a estrutura inicial de um projeto de console em C#.

- `dotnet build`  
  Compila o projeto.

- `dotnet run`  
  Executa o programa no terminal.

---

## 📦 Estrutura do Projeto

Arquivos principais do projeto:

1. `Program.cs`  
   Arquivo que contém o código do programa.

2. `OlaMundo.csproj`  
   Arquivo de configuração do projeto.

Framework utilizado:

- `.NET 10.0 (net10.0)`
